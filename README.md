# OpenLabs — Claude Code plugin

Learn to build AI agents by **directing** them, guided by a resident master craftsman — inside Claude Code. Draw what you want to learn as a teachboard board. Zero API keys (the LLM runs through Parallight's backend).

## Install (Claude Code)

```
/plugin marketplace add parallight/lab
/plugin install openlabs@parallight-cc
```

Then fully restart Claude Code and type `/openlabs` (menu: learn / lab / board / connect), or go straight to `/openlabs connect` / `/lab-login`.

More: <https://parallight.ai>

---

This repo is the public Claude Code marketplace. The MCP server (`plugins/openlabs/bundle/`) talks to the Parallight backend; it holds no secrets.
